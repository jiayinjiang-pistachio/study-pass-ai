## Claude Code 专属说明

- **规范以 `AGENTS.md` 为准**，本文件不重复其内容。若要修改规范，请只改 `AGENTS.md`。
- 开始任何任务前，先阅读与改动相关的现有文件，再动手。
- 涉及新增依赖、调整目录结构、改动构建配置等影响面较大的变更，**先说明方案并取得确认**，不要直接实施。
- 未经明确授权，不要执行 `git push`、`git rebase`、`git reset --hard`、强推、删除分支等操作。
- 完成改动后，运行 `pnpm build` 确认 `vue-tsc` 类型检查通过。
- 保持改动聚焦，不做需求之外的"顺手重构"。
